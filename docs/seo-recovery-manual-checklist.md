# SEO Recovery Trust Manual Checklist

Checklist ini untuk pemulihan trust domain Wisma Apollo setelah histori hack/spam. Kerjakan manual lewat Google Search Console, Google Business Profile, dan kanal backlink/review.

## 1. Search Console Bersih Total

- Cek **Manual Actions**.
- Cek **Security Issues**.
- Cek **Pages / Indexing**:
  - Indexed pages.
  - Not indexed pages.
  - 404.
  - Crawled but not indexed.
  - Duplicate/canonical issues.
- Cari query/URL mencurigakan:
  - `ebay`
  - `jepang`
  - `japan`
  - karakter Jepang/China asing
  - produk e-commerce asing
- Kalau ada URL spam masih indexed:
  - request removal di Search Console.
  - pastikan URL tersebut `410 Gone` atau `noindex`.

## 2. Redirect URL Lama

- Cari URL lama WordPress yang masih punya impresi/ranking di Search Console.
- Jangan biarkan URL lama penting menjadi 404.
- Redirect 301 ke halaman baru yang paling relevan.
- Prioritaskan URL lama dengan:
  - impression tinggi.
  - klik lama.
  - backlink.
  - ranking keyword lokal.

## 3. Submit Sitemap Baru

- Submit sitemap bersih:
  - `https://wisma-apollo.my.id/sitemap_index.xml`
- Pastikan sitemap hanya berisi URL bersih.
- Pastikan EN/ZH blog tetap tidak masuk index utama.
- Setelah submit, cek ulang Coverage/Pages beberapa hari kemudian.

## 4. Hidupkan Ulang Konten Lama yang Pernah Ranking

- Artikel ringan yang dulu menang jangan dibuang.
- Rebuild versi baru yang lebih rapi, lebih panjang, dan lebih relevan.
- Pertahankan intent keyword lama.
- Tambahkan:
  - gambar hero.
  - internal link ke homepage/landing page.
  - CTA reservasi.
  - FAQ kecil.
  - local entity seperti Kuala Kurun, Gunung Mas, Kalimantan Tengah.

## 5. Bangun Ulang Fresh Signal

- Update rutin artikel/blog.
- Posting rutin Google Business Profile.
- Minta review baru dari tamu.
- Dorong review natural dengan kata seperti:
  - hotel Kuala Kurun.
  - penginapan Kuala Kurun.
  - kamar bersih.
  - lokasi strategis.
- Bangun backlink/citation lokal baru.
- Request indexing manual untuk halaman utama:
  - homepage.
  - landing pages utama.
  - artikel lama yang direbuild.
  - halaman blog penting.
